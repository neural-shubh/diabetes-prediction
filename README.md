# 🧠 Diabetes Prediction using Machine Learning

## 📌 Overview

This project predicts whether a person has diabetes using machine learning models and compares their performance.

## 📊 Dataset

* PIMA Indians Diabetes Dataset
* Features include Glucose, BMI, Age, etc.

## ⚙️ Models Used

* Logistic Regression
* Decision Tree
* Random Forest
* SVM

## 🔥 Hyperparameter Tuning

Used GridSearchCV to optimize Random Forest for better accuracy.

## 📈 Results

Random Forest achieved the best performance (~82–85% accuracy).

## 🛠️ Tech Stack

* Python
* Pandas, NumPy
* Scikit-learn
* Matplotlib

## 🚀 How to Run

1. Clone the repo
2. Install dependencies:
   pip install -r requirements.txt
3. Run notebook or model.py
